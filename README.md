# India-Gate

India Gate (New Delhi) landmark map asset for FiveM. Streamed via the legacy
GTA5 asset pipeline — drop it in and it renders.

## What's included

- `india_gate.ydr` — main model
- `india_gate.ytd` — textures
- `india_gate_d.ytyp` + `_manifest.ymf` — archetype / metadata
- `india_gate_distantlights.ymap` — distant lights so it looks right at night

## Installation

1. Copy the resource into your `resources` folder.
2. Add to your `server.cfg`:

```cfg
ensure India-Gate
```

No frameworks or dependencies — it's a pure map/model stream.
